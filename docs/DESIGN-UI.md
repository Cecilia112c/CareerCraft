# CareerCraft DESIGN.md —— 前端美化提示词

> 用法：把本文件整体交给编码 Agent（Claude Code / Cursor 等），并附上一句：
> “请严格按照 docs/DESIGN-UI.md 重做 CareerCraft 前端的视觉层，不改业务逻辑和接口调用。”
>
> 结构参考 [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) 的九段式 DESIGN.md（视觉主题 → 色板 → 字体 → 组件 → 布局 → 层级 → 该做/不该做 → 响应式 → Agent 提示指南）。
> 风格基底：**Linear 的克制与精确** + **Vercel 的黑白对比和数字排版** + **Notion 的温和留白**，再用一点 **Stripe 式的渐变**点亮 AI 相关的时刻。
> 技术栈不变：Vue 3 + Vite + TypeScript + Element Plus 2.7；设计变量写在 `src/styles/main.css` 的 `:root` 中。

---

## 1. 视觉主题与氛围（Visual Theme & Atmosphere）

**一句话定位**：一个让求职者感到“安静、可靠、有掌控感”的专业工作台，而不是营销页。

- **关键词**：克制、精确、可信、留白、低噪音、偶尔的“AI 魔法时刻”。
- **整体气质**：像 Linear 一样大部分界面是中性灰白，只有可操作元素和 AI 相关元素使用品牌色；信息密度适中，靠层级和对齐建立秩序，不靠颜色和边框。
- **情绪曲线**：
  - 平时（浏览职位库、查看简历）：安静、中性，界面几乎“隐形”；
  - AI 工作时（生成简历、润色、面试评价）：出现柔和的渐变光晕和流动感，让用户感到“有东西在为我工作”；
  - 完成时：短暂、克制的成功反馈（绿色勾 + 200ms 淡入），不放彩带。
- **参考截图意象**：Linear 的 issue 列表、Vercel 的 Dashboard 卡片、Notion 的文档页留白、Stripe 首页渐变（只取一点）。

## 2. 色板与角色（Color Palette & Roles）

### 2.1 中性色（占界面 90%）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#FAFAFA` | 页面背景 |
| `--surface` | `#FFFFFF` | 卡片、面板、弹窗 |
| `--surface-muted` | `#F4F4F5` | 次级区域、输入框底、标签底 |
| `--border` | `#E4E4E7` | 默认 1px 分隔线 |
| `--border-strong` | `#D4D4D8` | hover 时的边框 |
| `--text-1` | `#18181B` | 标题、正文主色 |
| `--text-2` | `#52525B` | 正文次要、描述 |
| `--text-3` | `#A1A1AA` | 占位、元信息、时间 |

### 2.2 品牌与语义色（只在需要时出现）

| Token | 值 | 用途 |
|---|---|---|
| `--brand` | `#4F46E5`（靛蓝） | 主按钮、链接、选中态、焦点环 |
| `--brand-hover` | `#4338CA` | 主按钮 hover |
| `--brand-weak` | `#EEF2FF` | 选中行背景、标签底 |
| `--ai-gradient` | `linear-gradient(135deg, #6366F1 0%, #8B5CF6 50%, #EC4899 100%)` | **只用于 AI 相关**：AI 按钮描边/图标、生成中光晕、AI 结果卡片左侧色条 |
| `--success` | `#16A34A` / 浅底 `#F0FDF4` | 已具备技能、已替换、Offer |
| `--warning` | `#D97706` / 浅底 `#FFFBEB` | 技能缺口、待确认记忆、需要补充信息 |
| `--danger` | `#DC2626` / 浅底 `#FEF2F2` | 删除、被拦截的编造内容、失败 |
| `--salary` | `#E11D48` | 薪资数字（招聘场景惯例，保留但降低饱和度） |

### 2.3 规则

- 同一屏内品牌色面积不超过 10%；一个视图里最多只有 **1 个**实心主按钮。
- 渐变只出现在“AI 正在/已经为你做事”的地方，绝不用作页面大背景。
- 语义色一律“浅底 + 深字”的胶囊形式，不使用大面积实色块。
- 对比度：正文与背景至少 4.5:1（WCAG AA）。

### 2.4 暗色模式（可选，P2）

`--bg #09090B`、`--surface #18181B`、`--border #27272A`、`--text-1 #FAFAFA`、`--text-2 #A1A1AA`；品牌色提亮为 `#818CF8`。

## 3. 字体规则（Typography Rules）

- **字体族**：
  - 界面：`"Inter", "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", system-ui, sans-serif`
  - 数字/代码：`"Geist Mono", "JetBrains Mono", ui-monospace, monospace`（薪资、分数、token、版本号、时间）
  - 数字一律开启 `font-variant-numeric: tabular-nums`，列表中的分数和薪资要对齐。
- **字号阶梯**（只用这几档）：

| 角色 | 字号 / 行高 / 字重 | 字间距 |
|---|---|---|
| Display（首页大标题） | 40 / 48 / 600 | -0.02em |
| H1（页面标题） | 28 / 36 / 600 | -0.015em |
| H2（区块标题） | 20 / 28 / 600 | -0.01em |
| H3（卡片标题） | 16 / 24 / 600 | 0 |
| Body | 14 / 22 / 400 | 0 |
| Small（元信息） | 13 / 20 / 400 | 0 |
| Caption（标签、时间） | 12 / 16 / 500 | 0.01em |

- 标题用 600，正文用 400，**不要用 700 以上**；强调靠颜色深浅而不是加粗。
- 中英文混排时英文与中文之间保留一个半角空格（如“使用 Redis 缓存”）。
- 段落最大宽度 680px；JD 和面试对话等长文本行高 1.75。

## 4. 组件样式（Component Stylings）

### 4.1 按钮
- 高度：小 28 / 中 36 / 大 44；圆角 8px；水平内边距 12 / 16 / 20。
- **Primary**：`--brand` 实心、白字；hover 加深，按下时 `transform: scale(0.98)`。
- **Secondary**：白底、1px `--border`、`--text-1` 字；hover 背景改为 `--surface-muted`。
- **Ghost / Text**：无边框，hover 出现 `--surface-muted` 底。
- **AI 按钮**（“让 AI 修改”“生成定向简历”“开始面试”）：白底 + 1.5px 渐变描边（用 `border-image` 或伪元素实现）+ 左侧 ✦ 图标；运行中描边做 2s 循环的流光动画。
- 危险操作（删除）一律放在次要位置，用 Ghost 红字，并且必须二次确认。

### 4.2 卡片
- 白底、1px `--border`、圆角 12px、内边距 20px；**默认无阴影**。
- hover：边框改为 `--border-strong`，加上 `0 4px 12px rgba(0,0,0,.04)`，过渡 150ms。
- 选中：1px `--brand` 边框 + 左侧 3px 品牌色条。
- 职位卡片布局：第 1 行标题（H3）+ 右侧薪资（mono、`--salary`）；第 2 行元信息（Small、`--text-2`，用“·”分隔）；底部一行状态胶囊 + 匹配分。

### 4.3 输入框与表单
- 高 36px、圆角 8px、1px `--border`、背景 `--surface`；focus 时边框变 `--brand`，外加 `0 0 0 3px rgba(79,70,229,.12)` 焦点环。
- 标签在上方，13px、`--text-2`；必填用小圆点，不用红色星号。
- 指令输入框（简历工坊）：多行、最小 3 行，右下角显示“⌘/Ctrl + Enter 发送”的浅色提示。

### 4.4 标签 / 胶囊（Pill）
- 高 22px、圆角 6px、12px 字、内边距 0 8px；浅底深字。
- 技能标签：已具备 = 绿色系，缺口 = 琥珀色系，中性 = `--surface-muted`。

### 4.5 导航栏
- 高 56px、白底、底部 1px `--border`；滚动后加 `backdrop-filter: blur(12px)` 和 90% 不透明背景。
- Logo 左侧，导航项 14px、`--text-2`；当前项变为 `--text-1`，并在下方显示 2px 品牌色短线（宽度与文字等宽，带 200ms 滑动过渡）。
- 右侧：⌘K 搜索入口（P2）、“今日”提醒、头像菜单。

### 4.6 分段控件（Segmented）
- 外层 `--surface-muted` 底、圆角 8px、2px 内边距；选中项白底 + `0 1px 2px rgba(0,0,0,.06)`，切换时用滑块动画（150ms）。用于：词云来源切换、简历模式切换。

### 4.7 进度与 AI 状态
- 不用 Element Plus 默认的粗进度条；改成 2px 高的细线进度条，加上文字阶段说明。
- AI 运行中：在结果区放一个“骨架卡片”，用渐变 shimmer（1.2s 循环），配一句阶段文字（“正在读取岗位要求…”）。
- 流式结果（如果实现了 SSE）：每张修改卡片出现时自下而上淡入 8px，间隔 60ms。

### 4.8 修改结果卡片（简历工坊核心组件）
- 左侧 3px `--ai-gradient` 色条。
- 原文：13px、`--text-3`、删除线、`--danger` 浅底高亮被删除的片段。
- 新文：14px、`--text-1`、`--success` 浅底高亮新增片段（**按词级 diff 高亮，而不是整句变色**）。
- 理由：12px、`--text-3`，前面加 💡。
- 操作：Primary 小按钮“替换”+ Secondary“编辑后替换”+ Ghost“不用”；替换后卡片收起为一行“✓ 已替换 · 撤销”。

### 4.9 词云
- 中性背景，不加卡片阴影；字号范围 13–44px，权重越高字越重（400 → 600）。
- 已具备的技能 = `--brand` 的 4 级深浅，缺口 = 琥珀色的 4 级深浅，通用素质 = `--text-3`。
- hover：其他词透明度降到 0.35；点击后选中词下方出现 2px 下划线，并联动筛选下方职位。
- 右侧配“覆盖率环形图 + Top 10 横向条形图”，条形图用 6px 高、圆角 3px 的细条。

### 4.10 空状态
- 不用 Element Plus 默认插画；改为 48px 线性图标（Lucide 风格，1.5px 线宽）+ 一句标题 + 一句说明 + 一个主操作按钮。
- 文案要告诉用户“下一步做什么”，例如：“职位库还是空的 —— 安装书签后，在 BOSS 职位页点一下就能收藏。[安装书签]”。

### 4.11 弹窗 / 抽屉 / 提示
- 弹窗圆角 16px、内边距 24px，遮罩 `rgba(9,9,11,.4)` 加 4px 模糊；出现时 scale 0.96 → 1 + 淡入，180ms。
- 抽屉宽 480px，从右滑入。
- Toast：右下角，深色底 `#18181B` 白字、圆角 10px，3 秒消失；成功/失败用左侧小圆点区分颜色，而不是整块变色。

### 4.12 图标
- 统一用 Lucide（`lucide-vue-next`），16px / 20px 两档，线宽 1.5，颜色跟随文字。
- **删除界面里的 emoji 图标**（🎯📍💰🧠💡 等），全部换成对应线性图标；面向用户的文案里也不要用 emoji。

## 5. 布局原则（Layout Principles）

- **栅格**：4px 基准，常用间距 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。
- **内容宽度**：普通页面 1120px 居中；简历工坊和职位库详情为全宽多栏。
- **页面结构**：页面标题区（H1 + 一句说明 + 右侧主操作）→ 32px 间距 → 内容区。取消现在的大面积蓝色渐变横幅，改为白底 + 极淡的顶部渐变（`linear-gradient(180deg, #F5F3FF 0%, transparent 240px)`），只在首页和职位页使用。
- **分栏比例**：
  - 职位页：左列表 400px / 右详情自适应，详情区 sticky；
  - 简历工坊：左 220px（版本 + 模块）/ 中预览自适应（A4 居中，背景 `--surface-muted`）/ 右 400px（AI 助手）。三栏之间用 1px 分隔线，不用卡片阴影。
- **对齐**：同一区块内所有左边缘对齐；数字右对齐；按钮组靠右。
- **信息层级**：每张卡片只有 1 个视觉焦点（标题或数字），其余信息降级为 `--text-2 / --text-3`。

## 6. 层级与阴影（Depth & Elevation）

只用 4 级，优先用边框表达层级，阴影非常克制：

| 层级 | 用途 | 样式 |
|---|---|---|
| 0 | 页面、内嵌面板 | 无阴影，靠 `--bg` / `--surface` 区分 |
| 1 | 卡片 hover、下拉菜单 | `0 1px 2px rgba(0,0,0,.04), 0 4px 12px rgba(0,0,0,.04)` |
| 2 | 抽屉、浮动工具条、简历 A4 纸面 | `0 8px 24px rgba(0,0,0,.08)` |
| 3 | 弹窗 | `0 24px 48px rgba(0,0,0,.12)` |

- AI 运行中的区域可以加一圈柔和光晕：`0 0 0 1px rgba(99,102,241,.25), 0 8px 32px rgba(139,92,246,.15)`。
- 动效统一：时长 150ms（hover）/ 200ms（展开、切换）/ 300ms（页面级）；缓动 `cubic-bezier(0.2, 0, 0, 1)`；尊重 `prefers-reduced-motion`。

## 7. 该做与不该做（Do's and Don'ts）

**该做**
- ✅ 用留白和字号建立层级，而不是用颜色和边框。
- ✅ 每个页面只有一个最主要的操作，并且一眼能找到。
- ✅ AI 相关的元素统一用渐变标识，让用户分清“哪些是 AI 做的”。
- ✅ 所有数字（薪资、分数、覆盖率、token）用等宽数字。
- ✅ 加载状态用骨架屏 + 阶段文字，告诉用户“正在做什么”。
- ✅ 危险操作二次确认；可撤销的操作（替换、删除记忆）提供“撤销”入口。
- ✅ 所有可点击元素有 hover 和键盘 focus 样式（2px 焦点环）。

**不该做**
- ❌ 不要使用纯黑 `#000` 文字和纯黑阴影。
- ❌ 不要在一个视图里出现 3 种以上强调色。
- ❌ 不要用 emoji 当图标，不要用彩带/粒子庆祝动画。
- ❌ 不要把渐变铺满背景或用在普通按钮上。
- ❌ 不要给每张卡片都加阴影；不要卡片套卡片超过两层。
- ❌ 不要使用 Element Plus 默认的蓝色（#409EFF）和默认空状态插画——全部用设计变量覆盖。
- ❌ 不要让正文字号小于 13px，不要让行高小于 1.5。

## 8. 响应式（Responsive Behavior）

| 断点 | 宽度 | 变化 |
|---|---|---|
| Desktop | ≥ 1280px | 完整多栏 |
| Laptop | 1024–1279px | 简历工坊左栏收起为图标条；职位列表 360px |
| Tablet | 768–1023px | 职位页变为单栏，点击职位从右侧滑出详情抽屉；简历工坊的 AI 助手变为底部抽屉 |
| Mobile | < 768px | 导航收进汉堡菜单；只保证职位库、面试对话、简历预览可用；简历编辑提示“请在电脑上操作” |

- 触控目标不小于 40×40px。
- 简历 A4 预览在窄屏下按容器宽度等比缩放（`transform: scale()`），而不是重排。

## 9. 给编码 Agent 的执行指南（Agent Prompt Guide）

### 9.1 总体要求
1. **只改视觉层**：不修改 `src/api/`、路由、Pinia store、组件的 props/emits 和业务逻辑；不改后端。
2. 先在 `src/styles/main.css` 建立第 2～6 节的全部设计变量，并覆盖 Element Plus 主题变量（`--el-color-primary` 及其 light/dark 系列、`--el-border-radius-base`、`--el-font-family` 等）；然后逐页替换硬编码的颜色、字号、间距。
3. 新增依赖只允许：`lucide-vue-next`、`@fontsource/inter`、`@fontsource/geist-mono`（可选 `diff` 用于词级差异高亮）。
4. 抽取通用组件放到 `src/components/ui/`：`PageHeader`、`AppCard`、`Pill`、`SegmentedControl`、`EmptyState`、`AiButton`、`SkeletonCard`、`StatRing`。页面改为使用这些组件。
5. 每改完一个页面，确认 `npm run build` 通过，并在 1440px 与 1024px 两个宽度下截图自查。

### 9.2 按页面的具体改造

| 页面 | 改造要点 |
|---|---|
| `AppLayout.vue` | 56px 导航；滑动下划线；滚动模糊；去掉页脚的大块背景 |
| `LoginView.vue` | 左侧品牌区：一句价值主张 + 三条能力点（带线性图标）+ 极淡的渐变网格背景；右侧 400px 表单卡片，无阴影仅边框 |
| `HomeView.vue` | 顶部问候 + 一行关键数字（资料完整度、已收藏、已投递、面试场次，用大号 mono 数字）；四步引导改为横向时间线；投递漏斗改为横向分段条 |
| `JobsView.vue` | 页面标题区替换大横幅；词云区左右 2:1；职位卡片按 4.2；投递进度用细线步骤条；求职偏好卡片改为右上角紧凑摘要 |
| `ResumeStudioView.vue` | 三栏按第 5 节；中栏 A4 纸面用层级 2 阴影；右栏 AI 助手按“① 范围 ② 指令 ③ 结果”三段式，段落之间用 24px 间距和小号序号；结果卡片按 4.8；“保存版本”在有改动时显示琥珀色小圆点提示 |
| `ProfileView.vue` | 左侧锚点导航改成 Notion 式目录（当前项左侧 2px 竖线）；表单分组卡片；STAR 三栏用三列标题 + 浅色说明 |
| `InterviewRoomView.vue` | 对话气泡：面试官为白底 + 边框，候选人为 `--brand-weak` 底；评分用 5 段小条形而不是数字堆叠；报告页雷达图配色用品牌色 |
| `MemoryView.vue` | 偏好列表做成可内联编辑的行（hover 显示编辑/删除）；待确认记忆用琥珀色左边条；运行记录用时间线 + 状态点 |
| `ClipView.vue` | 精简为小窗口布局：顶部来源站点 + 标题，中间可编辑内容，底部固定操作栏 |

### 9.3 验收清单
- [ ] 全站搜索不到 `#409EFF`、`#1f5eff`、`#3370ff` 等旧色值，只引用 CSS 变量。
- [ ] 正文字号不小于 13px；所有数字使用等宽数字。
- [ ] 每个页面最多一个实心主按钮；AI 相关按钮统一使用 `AiButton`。
- [ ] 所有空状态使用 `EmptyState`，文案告诉用户下一步。
- [ ] 键盘 Tab 可以遍历所有可操作元素，焦点环清晰。
- [ ] 开启 `prefers-reduced-motion` 后没有循环动画。
- [ ] Lighthouse 可访问性分数 ≥ 90。
- [ ] `npm run build` 通过，功能回归：收藏职位、词云筛选、指定修改并替换、导出 PDF、模拟面试均正常。
